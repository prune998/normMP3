Installation — Windows
======================

1. Décompressez l'archive où vous voulez (par exemple dans
   C:\Program Files\NormMP3 ou sur le bureau).
2. Double-cliquez sur normmp3.exe.

Fichiers de travail
-------------------
Préférences (dans le dossier de démarrage) :

  memo.txt                 mémorisation du gain cible
  normmp3.conf             thème clair/sombre

Fichiers normalisés : chaque MP3 importé est copié dans un dossier
« Fichiers_normalises » créé dans le dossier d'origine du fichier ;
les originaux ne sont jamais modifiés.

Lecteur : cliquez sur un fichier de la liste « Sélection » pour
l'écouter (lecture/pause, ±10 s).

Pour travailler dans un dossier précis, mettez un raccourci vers
normmp3.exe dans votre dossier de musique, ou lancez-la depuis une
invite de commandes ouverte dans ce dossier :

  cd C:\Users\vous\Musique\mes-mp3
  normmp3.exe

Utilisation
-----------
1. Fichiers ▸ Choisir les fichiers : sélectionnez un ou plusieurs MP3
   (les fichiers sont copiés dans Fichiers_normalises/).
2. Action ▸ Analyse : mesure des niveaux.
3. Action ▸ Traitement : normalisation au gain cible.
4. Action ▸ Choix du gain cible : 85 à 93 dB (89 par défaut).
