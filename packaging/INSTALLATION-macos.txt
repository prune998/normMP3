Installation — macOS
====================

1. Décompressez l'archive (double-clic).
2. Glissez NormMP3.app dans le dossier Applications.
3. Premier lancement : l'application n'est pas distribuée via l'App
   Store, macOS peut refuser de l'ouvrir (« ne pas vérifier le
   développeur » ou « est endommagé »). Voir « Déquarantaine »
   ci-dessous.

Déquarantaine (premier lancement bloqué)
----------------------------------------
Méthode graphique :

  - Clic droit sur NormMP3.app ▸ Ouvrir ▸ bouton « Ouvrir » ;
  - ou Réglages Système ▸ Confidentialité et sécurité ▸ section
    Sécurité : « NormMP3 a été bloqué… » ▸ « Ouvrir quand même ».

Méthode terminale (fonctionne toujours) :

  xattr -dr com.apple.quarantine /Applications/NormMP3.app

Cette opération n'est nécessaire qu'une seule fois, après le
téléchargement de l'archive.

Fichiers de travail
-------------------
L'application crée, dans le dossier courant au démarrage :

  memo.txt                 mémorisation du gain cible
  Fichiers_normalises/     copies normalisées de vos fichiers

Lancée depuis le Finder, elle utilise votre dossier personnel.
Pour travailler dans un dossier précis (par exemple un dossier
« Musique » contenant vos MP3), lancez-la depuis un terminal :

  cd /chemin/vers/mes/mp3
  open -a NormMP3

Utilisation
-----------
1. Fichiers ▸ Choisir les fichiers : sélectionnez un ou plusieurs MP3
   (les fichiers sont copiés dans Fichiers_normalises/).
2. Action ▸ Analyse : mesure des niveaux.
3. Action ▸ Traitement : normalisation au gain cible.
4. Action ▸ Choix du gain cible : 85 à 93 dB (89 par défaut).
